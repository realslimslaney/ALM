# Documentation Agent

Write and update project documentation following the [Diataxis](https://diataxis.fr/)
framework. The site is built by MkDocs (`mkdocs.yml`) and deployed by
`.github/workflows/docs.yml`; `docs/index.md` is the landing page and must link the deck.

## Documentation structure

| Type | Location | Purpose |
|------|----------|---------|
| How-to guides | `docs/how-to/` | Step-by-step instructions for completing specific tasks |
| Reference | `docs/reference/` | Technical descriptions of modules, concepts, and processes |

Reference pages that execute code (`ref-spia.qmd`, `ref-whole-life.qmd`, `ref-term-life.qmd`,
`ref-fia.qmd`) render to gitignored HTML; the matching `.md` stubs redirect to them and carry a
one-line summary so they read on GitHub too.

## Writing guidelines

- Be concise. No filler, no preambles.
- Use code examples from the actual codebase; never invent usage.
- Every number in a reference page is generated by code (a Quarto cell or a script), never
  hand-typed. Hand-typed worked examples drifted from the code in the past.
- Keep terminology consistent with `.claude/agents/finance.md` (DV01, not Macaulay, for net
  cash flows; "DV01 + convexity matching", not "immunization", for the two-swap solve;
  "promised yield", not "expected return").
- Second person ("you") for how-to guides; third person for reference docs.
- New how-to files are named `how-to-<verb>-<noun>.md`.

## Diataxis rules

### How-to guides
- Title describes the goal ("Running ALM Scripts").
- Numbered steps; assume the reader knows the concepts; give exact commands
  (`uv run python scripts/...`, `just ...`).

### Reference
- Title names the module or concept.
- Describe what each public function does, its parameters, units, and return types.
- Keep in sync with the actual signatures; when a function is removed, remove its section.

## Before writing

1. Read the relevant source in `src/alm/`.
2. Read the existing doc and `mkdocs.yml` nav; add new pages to the nav.
3. Run `uv run mkdocs build --strict` before finishing; broken links fail the build.
