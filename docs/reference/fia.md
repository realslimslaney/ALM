A **fixed indexed annuity (FIA)** credits interest tied to an equity index, subject to a floor,
a cap and a participation rate, so the account value never falls but gives up part of the
upside. The reference page shows how the crediting formula transforms index returns, grows an
account value under bull, moderate and bear scenarios, projects expected cash flows on SOA 2012
IAM mortality, reports sensitivity to the cap, participation rate and discount rate, and prices the
crediting call spread to show how an option budget sets the cap. It is
an executable Quarto page (`ref-fia.qmd`) rendered on the docs site; this stub redirects to it.
