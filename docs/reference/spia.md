A **single premium immediate annuity (SPIA)** pays the policyholder a level income for life,
optionally guaranteed for a certain period, in exchange for one up-front premium. The reference
page prices a SPIA at its net single premium on SOA 2012 IAM mortality, shows the expected
cash flows, compares certain periods, and reports duration and convexity across discount rates.
It is an executable Quarto page (`ref-spia.qmd`) rendered on the docs site; this stub redirects
to it.
